RaceDay.MVC

Your Race. Your Challenge. Your Victory.
A modern ASP.NET Core MVC web application designed to manage and participate in race day events across South Africa.

Project Overview

RaceDay.MVC is a web-based application that allows users to explore upcoming race events, register as participants, manage their profiles and keep track of their registered events.
The application also provides organiser functionality to manage race events, making race day management easier and more organised.

 Features

Participant Features

- Browse upcoming race day events.
- View detailed event information.
- Register for an account.
- Secure login and logout.
- View and manage participant profiles.
- View registered events and event history.

Organiser Features

- Create new race events.
- View and manage existing events.
- Edit event information.
- Delete events.
- Access the organiser dashboard.

 User Interface

- Modern blue and black design.
- Responsive page layouts.
- Easy-to-use navigation.
- Clean and organised interface.

Project Objectives

The main objectives of RaceDay.MVC are to:

- Make race event information easily accessible.
- Simplify participant registration.
- Allow participants to manage their event activities.
- Help organisers manage race events efficiently.
- Provide a user-friendly online race management platform.
