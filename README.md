# RaceDay.MVC-Part-3

RaceDay.MVC is an ASP.NET Core MVC web application for managing and joining race day events in South Africa.

## Features
- View Upcoming Race Day Events
- View Event Details
- Participant Registration and Login
- Participant Profile and Event History
- Admin can Create, Edit and Delete Events
- Blue and Black Modern UI

## Technologies Used
- ASP.NET Core MVC (C#)
- Entity Framework Core
- SQL Server
- Bootstrap 5
- HTML / CSS

## How to Run
1. Clone the repository
2. Open `RaceDay.MVC.sln` in Visual Studio
3. Update connection string in `appsettings.json` if needed
4. Press `F5` or `Ctrl + F5` to run
5. App runs on `https://localhost:7141/`

## Pages
- Home - Upcoming Race Day Events
- Participant - Browse Events
- Profile - My Registered Events
- Admin - Manage Events
